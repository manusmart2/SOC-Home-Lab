# Cybersecurity Home Lab

A hands-on cybersecurity home lab designed to build practical experience in **SOC operations, SIEM monitoring, endpoint security, Windows security, Active Directory, and log analysis**.

The lab consists of virtualized Windows and Linux systems connected in an isolated test environment. The primary focus is collecting security telemetry, monitoring endpoints, generating security events, and investigating suspicious activity.

---

## 🎯 Objectives

The main objectives of this lab are:

* Build and maintain a practical cybersecurity lab environment
* Deploy and configure a **Wazuh SIEM/XDR environment**
* Connect and monitor multiple endpoints
* Collect and analyze Windows and Linux security logs
* Investigate suspicious activities and security events
* Practice endpoint monitoring and alert investigation
* Build an **Active Directory security lab**
* Troubleshoot agent connectivity and networking
* Understand how security events move from endpoints to a SIEM
* Develop practical SOC Analyst investigation skills

# 🛡️ Wazuh Home Lab

The Wazuh environment is the primary monitoring component of the lab.

The lab currently includes a **Wazuh Manager with four connected agents**, allowing security telemetry to be collected from multiple endpoints.

## Wazuh Components

### Wazuh Manager

Responsible for:

* Receiving events from agents
* Processing security telemetry
* Generating security alerts
* Monitoring endpoint activity
* Providing centralized security visibility

### Wazuh Agents

Four agents are connected to the Wazuh environment.

The agents are used to practice:

* Endpoint monitoring
* Log collection
* Security event detection
* Agent connectivity troubleshooting
* Alert investigation
* Host-based security monitoring

# 📊 Security Monitoring

The lab is used to monitor security-related activity such as:

* Windows security events
* Linux system logs
* Authentication activity
* Process activity

# 🔎 Log Analysis

A dedicated part of the lab focuses on analyzing security logs.

The workflow is:

```text
Endpoint Activity
       │
       ▼
Log Generation
       │
       ▼
Wazuh Agent
       │
       ▼
Wazuh Manager
       │
       ▼
Security Alert
       │
       ▼
Analyst Investigation
       │
       ▼
Identify Suspicious Activity
       │
       ▼
Document Findings
```

During investigations, I practice identifying:

* Suspicious processes
* Unusual authentication activity
* PowerShell execution
* Potential persistence mechanisms
* Abnormal endpoint behavior
* Indicators of compromise
* Relevant security events

# 🌐 Networking

Networking is an important part of the home lab because the security monitoring infrastructure depends on communication between the manager and endpoints.

I have worked with:

* IP addressing
* Virtual machine networking
* Host-only networking
* Bridged networking
* Connectivity testing
* Agent-to-manager communication
* Network troubleshooting

Basic connectivity testing is performed using tools such as:

```bash
ping <IP_ADDRESS>
```

Network configuration is adjusted depending on whether systems need:

* Internet access
* Communication with the host
* Communication with other virtual machines
* Communication with the Wazuh Manager
